# Upload-Post Integration

Cross-post your ShortGPT videos to TikTok and Instagram automatically using [Upload-Post](https://upload-post.com).

## What is Upload-Post?

Upload-Post is an API that allows you to upload videos to multiple social media platforms (TikTok, Instagram, YouTube, LinkedIn, etc.) with a single API call.

- **Website:** https://upload-post.com
- **API Docs:** https://docs.upload-post.com
- **Free tier available**

## Setup

1. Create an account at [upload-post.com](https://upload-post.com)
2. Connect your TikTok and/or Instagram accounts in the dashboard
3. Get your API key from the dashboard
4. In ShortGPT, go to the **Config** tab
5. Enter your Upload-Post API Key and Username
6. Click Save

## Usage

1. Go to the **Short Automation** tab
2. Configure your short as usual
3. Check the **📱 Cross-post to TikTok/Instagram** checkbox
4. Select which platforms you want to post to (TikTok, Instagram, or both)
5. Optionally add a custom caption
6. Click **Create Shorts**

After the video is generated, ShortGPT will automatically upload it to your selected platforms.

## Features

- **Automatic cross-posting:** Videos are uploaded immediately after generation
- **Multi-platform:** Post to TikTok and Instagram simultaneously
- **Custom captions:** Add your own caption or use the video title
- **Status feedback:** See if the cross-post succeeded or failed

## Supported Platforms

Upload-Post supports:
- TikTok
- Instagram (Reels)
- YouTube Shorts
- LinkedIn
- Pinterest
- Twitter/X
- Facebook

## Troubleshooting

### "Upload-Post API key or username is missing"
Make sure you've entered both the API key and username in the Config tab.

### "Cross-post failed"
- Check that your Upload-Post account has the platforms connected
- Verify your API key is correct
- Check the Upload-Post dashboard for any account issues
